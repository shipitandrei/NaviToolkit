# NaviToolkit
_Formerly KumonConnectTouchPatcher_

NaviToolkit allows you to use Kumon Connect without a stylus, and view your upcoming worksheets. more to come soon

Honestly, touch input sucks, I understand why this isn't officially supported. For best experience, use an electric capacitive stylus with a fine tip, and gloves for homemade palm rejection.

NaviToolkit may break with updates. Please treat the touch patching feature as a temporary fix while you wait for a usable, officially supported stylus.  

## Instructions for Use
1. Install a userscript manager
2. [Install the script](https://raw.githubusercontent.com/shipitandrei/NaviToolkit/main/navitoolkit.user.js)
