# KumonConnectTouchPatcher
Currently, the Kumon Connect PWA only supports stylus input. This locks Kumon students to expensive tablets with built in styluses. This userscript allows students to use homemade styluses or cheap capacitive styluses.

## Instructions for Use
1. Install a userscript manager
2. Install the script
