# KumonConnectTouchPatcher
Kumon Connect currently **requires** a compatible tablet and stylus, which means students are effectively required to have rather expensive hardware like an iPad or a Samsung tablet. This userscript allows students to use homemade styluses, cheap capacitive ones, or even their fingers.

## Instructions for Use
1. Install a userscript manager
2. [Install the script](https://raw.githubusercontent.com/shipitandrei/KumonConnectTouchPatcher/main/kumonpatch.user.js)

Too confusing? You have access to Google. I believe in you. 

## Known Bugs
- Delay while using touch input
- Sometimes Cancel and Finish Studying button doesn’t work
