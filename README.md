# KumonConnectTouchPatcher
Kumon Connect currently requires a compatible tablet and stylus, which means students are effectively required to have rather expensive hardware like an iPad or a Samsung tablet. This userscript allows students to use homemade styluses, cheap capacitive ones, or even their fingers. This userscript is not an official Kumon tool. I am not affiliated with Kumon in any way.

Honestly, touch input sucks, I understand why this isn't officially supported. For best experience, use an electric capacitive stylus with a fine tip, and gloves for homemade palm rejection.

## Instructions for Use
1. Install a userscript manager
2. [Install the script](https://raw.githubusercontent.com/shipitandrei/KumonConnectTouchPatcher/main/kumonpatch.user.js)

Too confusing? You have access to Google. I believe in you.
